   # Loan Approval Prediction using Decision Tree
   
   Predict whether a bank customer's loan application will be approved.
   
   ## Results
   - Accuracy: 78% (optimized depth=2)
   - Key predictor: Credit History
   
   ## Dataset
   614 loan applications with 13 features
   
   ## Tech
   Python, pandas, scikit-learn, Decision Tree
   
   ## Accuracy Improvement
   - Base model (depth=5): 74.8%
   - Optimized model (depth=2): 78%
